# Аудит перевода

## Стандарт терминов (принятый в этом выпуске)
- tire track → «след колёс» (не «колея»: колея в русском языке — выбоина/углубление).
- lane position → «положение в полосе».
- blind spot → «слепая зона».
- staggered formation → «ступенчатый строй».
- threshold braking → «торможение на пределе сцепления».
- HOV → «полоса HOV» (с пояснением «полоса для транспорта с пассажирами»).
- advisory speed → «рекомендуемая/предупреждающая» — только если это подтверждено; иначе «безопасная скорость».
