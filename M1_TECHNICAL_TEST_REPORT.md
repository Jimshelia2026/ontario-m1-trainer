1. Структурная проверка данных (node): 299 вопросов, уникальные ID, по 4 варианта, валидные индексы ответа, непустые объяснения и источники — ошибок нет.
2. Проверка на английские варианты: найдено 0.
3. Смоук-тест в Chromium (Playwright), файл tests/smoke_v4.py: 17 из 17 проверок пройдено (навигация по всем вкладкам, загрузка 299 вопросов, 0 английских вариантов, 48 изображений знаков загружаются, практика: подсветка только после ответа, симуляция: нет подсказок до отправки, мобильный экран 390 px без горизонтальной прокрутки, нет ошибок JavaScript).
4. Тест уроков, файл tests/lessons_test.py: 15 из 15 уроков открываются, все 15 схем загружаются, ошибок JavaScript нет.
5. Визуальная проверка 13 схем (отрисовка в Chromium) и исправление переполнения текста в схеме полосы.

## Не выполнено
- Тестирование в Safari (macOS и iPhone): не выполнялось — нет доступа.
- Тестирование на живом GitHub Pages: не выполнялось.
- Полный набор тестов из архива (tests/full_test.py из прошлых версий) не запускался: он рассчитан на 87 вопросов.
- Тест миграции прогресса (старые версии → v4) в этом проходе не выполнен отдельно; изменения версий (m1-166, m1-200 — версия 2) не проверены в браузере.
- Схемы из архива (controls, inspection, helmet, intersection, distance, hazard) визуально не проверены.
