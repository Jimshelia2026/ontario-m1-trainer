Ontario M1 — тренажёр знаний (этап 2)

ЗАПУСК
1. Распакуйте архив в любую папку.
2. Откройте файл index.html в браузере (Chrome, Edge, Firefox, Safari).
   Интернет не нужен. Сервер не нужен.

СОСТАВ
index.html      — интерфейс и стили
app.js          — логика: обучение, практика, симуляция, ошибки, знаки, прогресс
questions.js    — банк вопросов (32 вопроса, источник — MTO Motorcycle Handbook)
signs.js        — данные о 48 дорожных знаках (источник — MTO Driver's Handbook)
assets/signs/   — изображения знаков, извлечены из PDF и увеличены ×2

ВАЖНО
- Вопросы и знаки составлены по официальным руководствам MTO.
  Это НЕ настоящие экзаменационные билеты.
- Формат официального экзамена (число вопросов, время, проходной балл) в приложении не задан.
- Прогресс хранится в localStorage этого браузера. Очистка данных браузера его удалит.
