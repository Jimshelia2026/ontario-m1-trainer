# Ontario M1 Trainer — v6.3 (локальный предварительный просмотр, обновлённая сборка)

Локальная сборка. Не опубликована, GitHub не изменялся. Публичный сайт v6.2 не затронут.

## Запуск приложения
1. В папке проекта запустите статический сервер: `python3 -m http.server 8080`
2. Откройте http://127.0.0.1:8080/index.html

Открытие index.html двойным щелчком возможно, но для изображений и localStorage надёжнее сервер.

## Тесты
Установка тестовой зависимости: `npm install` (нужен jsdom).
- `npm test` — модульные тесты генератора, восстановления, отпечатка банка, предела знаков и jsdom-сквозные тесты.
- `npm run test:browser` — браузерные тесты Chromium (Playwright). Перед запуском поднимите сервер на порту 8630:
  `python3 -m http.server 8630 --bind 127.0.0.1`

## Что в этой сборке
- Симуляция «M1 — 64 вопроса»: 20 знаков, 20 правил, 24 мотоцикл; порог модели 52 из 64. Тренировочная модель, не официальный экзамен.
- Восстановление незавершённой симуляции проверяет всю сессию по тем же правилам, что и генератор (состав, дубликаты, допуск вопроса, статус проверки, перестановки и ответы).
- Отпечаток банка вопросов сохраняется с сессией. При изменении банка сессия не продолжается: данные копируются в резервную запись `m1trainer.v63.exam64.stale.*`, пользователь получает объяснение и может начать новую симуляцию.
- Предел: не более двух знаков одного семейства в симуляции (жёсткое ограничение, проверено на 10 000 сессий).
- В разборе у каждого вопроса указан статус проверки; ссылки на законы по вторичным источникам помечены как непроверенные по e-Laws.

Сессии, созданные до этой сборки, не имеют отпечатка банка и будут отклонены: начните новую симуляцию.

## Структура
- index.html, app.js, questions.js (275 вопросов), lessons.js, signs.js, exam64.js (движок и интерфейс симуляции 64)
- assets/ — изображения знаков и SVG-схемы
- data/ — классификация, зафиксированная копия v6.2 для пересборки, отчёт сборки
- tools/build_data.js — пересборка данных (`npm run build:data`)
- tests/v63/ — актуальные тесты v6.3
- tests/legacy_v62/ — устаревшие тесты v6.2 (не входят в набор проверок, см. README внутри)
