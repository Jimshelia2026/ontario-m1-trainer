# Как обновить сайт на GitHub (пошаговая инструкция)

Сайт: https://jimshelia2026.github.io/ontario-m1-trainer/

## 1. Скачайте архив
Скачайте файл архива (в конце этой инструкции указано его название) на компьютер.

## 2. Распакуйте архив
На Mac: дважды щёлкните по архиву. Появится папка. Откройте её.

## 3. Откройте репозиторий
В браузере (Safari или Chrome) откройте https://github.com/Jimshelia2026/ontario-m1-trainer и войдите в аккаунт.

## 4. Загрузите файлы
1. Нажмите зелёную кнопку **Add file** → **Upload files**.
2. Перетащите в окно все файлы из распакованной папки, включая папки `assets` и `tests`.
3. Если GitHub спрашивает, заменить ли файлы, выберите замену.
4. **Не загружайте** папку `archive_old_reports` — это старые отчёты.

## 5. Сохраните изменения
Внизу страницы в поле «Commit changes» напишите: «Обновление v4». Нажмите **Commit changes**.

## 6. Подождите
Подождите 1–3 минуты: GitHub публикует сайт.

## 7. Обновите страницу
На Mac: нажмите **Cmd + R**. Если изменений не видно, закройте вкладку и откройте сайт заново.
На iPhone: закройте вкладку Safari и откройте сайт снова.

## 8. Проверьте
- Вкладка «Прогресс»: вверху должно быть «Всего вопросов: 299».
- Вкладка «Дорожные знаки»: 48 знаков, варианты ответа на русском.
- Вкладка «Уроки»: 15 уроков.

## 9. Ваш прогресс
Прогресс хранится в браузере. Замена файлов на GitHub его не удаляет. Не очищайте данные сайта в Safari. Вопросы, у которых изменился смысл (m1-166, m1-200), начнут повторяться заново; история ошибок сохраняется.

Название архива: Ontario_M1_Trainer_v4_CORRECTED_NOT_VERIFIED.zip
