# Обновление тренажёра Ontario M1

## Перед заменой
1. Откройте текущий тренажёр на том же устройстве и в том же Safari, в котором вы занимались. Данные хранятся в браузере; не очищайте данные сайта.
2. Для дополнительной страховки сохраните копию существующего репозитория через GitHub → Code → Download ZIP.

## Как заменить файлы
1. Скачайте `Ontario_M1_Trainer_Improved.zip` и дважды нажмите на архив на Mac, чтобы распаковать.
2. Откройте GitHub: `https://github.com/Jimshelia2026/ontario-m1-trainer`.
3. В корень репозитория загрузите **с заменой** `index.html`, `app.js`, `questions.js`, `signs.js`, `lessons.js`. Не загружайте сам ZIP вместо его содержимого.
4. В репозитории откройте папку `assets`. Убедитесь, что в `assets/signs` находятся прежние 48 JPG, а в **новой** папке `assets/diagrams` — 14 SVG. Если загрузка папки перетаскиванием не работает, создайте папки через интерфейс GitHub и загрузите файлы в каждую отдельно.
5. Нажмите `Commit changes`. Если GitHub просит подтвердить замену файлов, подтвердите.
6. Подождите публикации GitHub Pages (обычно несколько минут) и откройте `https://jimshelia2026.github.io/ontario-m1-trainer/`.
7. В меню должна появиться вкладка **«Визуальные уроки»**. В «Прогресс» будет **105 вопросов**. В уроках должно быть 15 тем и видны схемы.
8. Если Safari показывает старую страницу, закройте вкладку, откройте сайт заново и обновите страницу. Не очищайте данные сайта, чтобы не потерять прогресс.

## Что важно знать
Это расширенная учебная версия, **не официальный экзаменационный тест DriveTest**. Проверка всех материалов на актуальность по состоянию на день экзамена остаётся необходимой. Новые схемы — учебные, упрощённые. Интерактивный браузерный тест в среде сборки был заблокирован, поэтому после публикации нужно вручную проверить все вкладки и несколько вопросов.
