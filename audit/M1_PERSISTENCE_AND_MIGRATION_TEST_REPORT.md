# Отчёт о тестах сохранения, возобновления и миграции (версия 6.1)

Среда: Chromium (Playwright, headless). Сайт собран в подкаталоге и запущен локально. Тесты выполнены на распакованном ZIP версии 6.1.
**Не выполнено:** Safari (Mac, iPhone) — WebKit не скачивается в этой среде (сеть блокирует загрузку); живой GitHub Pages.

## Что проверено сценариями
- **Обучение:** позиция 5 переживает перезагрузку, переход на другую вкладку и закрытие и повторное открытие браузера.
- **Уроки:** два пройденных урока сохраняются после перезагрузки; открывается следующий непройденный (3 из 15).
- **Симуляция (10 вопросов):** курсор на 6-м вопросе, ответы на 1–3, изменённый ответ на 3-м; после перезагрузки текст вопроса тот же; учтено ровно 3 ответа; повторная перезагрузка не пересчитывает результат.
- **Практика:** обратная связь после ответа переживает перезагрузку; следующий вопрос сохраняется; порядок последовательный; за 60 показов в практике не появился ни один вопрос из карантина; после последнего активного вопроса показано сообщение о завершении.
- **Викторина знаков:** выбранный ответ и счётчик сохраняются; после «Далее» новый знак без ответа; счётчик записан в хранилище.
- **Миграция:** статистика, закладки, размер текста и тема переносятся из версии 2; старый ключ не удаляется.
- **Версии вопросов:** при изменении версии (m1-166, 1 → 3) признаки освоения сбрасываются, история ответов сохраняется.
- **Сбои:** повреждённый файл — предупреждение и сохранённая копия; сбой записи — предупреждение пользователю.
- **Импорт** резервной копии применяется.
- **Мобильный вид 390 px:** горизонтальной прокрутки нет ни на одной вкладке.

## Ошибки, найденные при тестировании (и исправленные)
1. Страница не отрисовывалась: не была объявлена переменная состояния (исправлено).
2. Нельзя было начать заново незавершённую симуляцию: кнопки не было (исправлено).
3. Тест практики проходил не больше 80 вопросов при 250 активных (исправлено в тесте).
4. Фикстура активных вопросов содержала старую формулировку m1-048 и падала на H1 (исправлено: фикстура генерируется из текущих данных; её нужно пересоздавать при каждом изменении вопросов).

## Ограничения
- Safari и iPhone не проверены.
- Экспорт (скачивание файла) не проверен; импорт проверен.
- Режим «повтор» (случайный выбор) отдельным тестом не покрыт.
- В режиме обучения порядок вариантов после перезагрузки перемешивается заново.
